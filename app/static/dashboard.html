Why most results say "unprofitable"

The gap is usually smaller than the fees. A trade pays the V3 fee (5 bps) and the V2 fee (30 bps), so WETH has to be more than 35 bps cheaper on one pool before any size makes money, and gas comes on top. These two pools are among the most watched on Ethereum, and bots close bigger gaps inside the same block, usually before we can see them. An honest "unprofitable, by this much" is the expected answer. The contract tests force a gap to prove the profitable path works.

Simulated, never sent. Sending a real transaction needs a funded wallet and a private key, which costs money and puts a key on a server. Instead, the lab runs the contract against the current mainnet state with a read-only call that gives the same answer the chain would at that block, with no key and no cost.

How the hosted demo does it. The free host can't run a mainnet copy, so each simulation temporarily places the contract's code at an address for one read-only call on the free public endpoint. If the endpoint can't do that, this page says "unavailable" instead of showing invented numbers.
